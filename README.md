
# Enable Scotland Prototype 2

Client staging prototype exported from Figma Make and prepared for GitHub Pages.

Original Figma project: https://www.figma.com/design/oOp1GVCGRsZzv9Eq6ZaQAl/Design-System-for-Enable-Scotland.

## Running locally

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.

## Building

Run `npm run build` to generate the static site in `dist/`.
